# kagayaki

学習用シリーズ「kagayaki」。単元ごとにファイルを分けて保存しています。

| 単元 | 内容 | ファイル |
|---|---|---|
| rika（理科） | 化学式れんしゅう帳：元素記号・化学式・化学反応式の「おぼえる」/「レベル別クイズ」（ふくしゅう機能つき） | [rika/index.html](rika/index.html) |
| sugaku（数学） | 図形れんしゅう帳：角度の計算（三角形・平行線・多角形）と合同の条件の「おぼえる」/「レベル別クイズ」 | [sugaku/index.html](sugaku/index.html) |

## 使いかた
- `rika/index.html` や `sugaku/index.html` をブラウザで開くだけでも使えます（インターネット接続があればフォントがきれいに表示されます）。
- クイズの記録は、開いた端末のブラウザに自動で保存されます。
